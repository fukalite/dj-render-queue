# Technology Stack

## Core Technologies
- **Language:** Python (>= 3.12)
- **Framework:** Django (>= 5.2)

## Tooling & Infrastructure
- **Task Runner / Entrypoint:** just (used for everything including testing, linting, formatting)
- **Packaging & Build:** Hatchling and Hatch-VCS
- **Linting & Formatting:** Ruff (Python), mypy (type checking)

## Testing
- **Test Framework:** pytest (with pytest-django, pytest-mock)
- **Fixtures/Factories:** factory-boy
- **Coverage:** pytest-cov
